# U1 implementation evidence

## Scope and interfaces

Pure-Lua modules live at `lua_repl_mcp/` and import no manager/native modules.
`require('lua_repl_mcp').null` is a stable table identity; use `rawequal` to
identify it. No globals or output functions are installed or replaced.

Internal seams for U2: `contracts.from_json(tool, text)` decodes and validates
all seven tool inputs, returning a fresh input or `nil, error`;
`contracts.validate(tool, decoded)` accepts decoded codec data (array/object
shape matters). `evaluator.execute(input, options)` returns direct completed/
failed payloads. `evaluator.from_json(text, options)` includes strict decode.
Options are `max_depth`, `max_bytes`, `diagnostic_bytes`; positive integral
limits are validated before execution. Diagnostic limits must hold the notice.
`codec.encode`/`decode` return `nil, {reason,path}` on invalid data. `codec.array`
marks protocol arrays, not user return types. U2 owns protocol envelopes and
MCP isError/text duplication; U7 owns coupled transport budgets.

## Codec strategy and diagnosis

No implementation existed at baseline e48b82f. The preserved public-entrypoint
reproducer failed its import. A stub sentinel alone would conceal the remaining
U1 gap, so this change implements the owning data boundary and evaluator.

The codec is project-owned pure Lua, with no external dependency. Exact decimal
mantissa/exponent inspection precedes binary conversion; huge exponents are
saturated without expanding zero strings. Integral tokens outside ±(2^53−1)
are rejected before rounding. Finite nonintegral tokens use Lua binary64
conversion; post-conversion integral unsafe values are also rejected. Output
checks Lua integer and float subtypes identically. UTF-8 validation rejects
surrogates, overlong sequences and invalid bytes. JSON surrogate pairs are
combined, lone surrogates and duplicate object keys rejected. Raw user tables
use next/rawget, never __pairs/__index/__len/__tostring. Empty user tables
normalize to objects. Active-path cycle detection permits repeated acyclic data.
No partial serialized values escape a failed result.

The evaluator compiles a complete text chunk once in existing `_G`, executes
once through xpcall, packs explicit returns, and converts nil positions to the
sentinel. Serialization happens after execution; errors preserve side effects.
Diagnostics represent arbitrary thrown objects by type without user conversion;
invalid bytes become literal `\xHH`. Loss flags and a readable notice accompany
escaping/truncation. Combined message/traceback bytes include the notice.

## Review and remaining gates

An implementation self-review identified an unsafe diagnostic path: unsupported
object keys could call `tostring` on a hostile table key while rejecting input.
The owning object validator now rejects non-string keys at the containing pointer;
`operator_limits_and_hostile_argument_keys` proves no conversion is invoked.
Self-review also added explicit evaluator-limit validation and actual default
16 MiB/128-level/64 KiB boundaries rather than only small configured limits.
All revised checks were rerun successfully.

Independent implementation review has **not** occurred. This activation exposes
no delegation/reviewer capability; `software-development` skill loading reports
unavailable. This is not claimed as review convergence or full U1 acceptance.
The implementation and reproducible evidence are available for independent review;
review remains a required delivery gate. U2–U9 were not started. No live handler,
manager, install or process behavior is claimed by these tests.
