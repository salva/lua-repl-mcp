   particular encode/decode paths resumable only where evidence requires it.
2. F03's prohibition on forwarding a validated original envelope forces token-span
   extraction machinery. A smaller candidate carries the original JSON as JSON

   fix completed-cancellation reservation handling before replacing ownership.

   client/browser campaigns should follow unresolved scaling or relevant changes,
