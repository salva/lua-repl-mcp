including when the code under test fails. Filename evolution accidentally routes
U12 process-spawning scripts through pure-Lua discovery. Existing separate
watchdog idioms leave partial-frame and total-poll gaps. Real process containment
is a correctness gate, not a historical ritual; more duplicated wrappers are not.
Preserve historical expected-red classification explicitly.
