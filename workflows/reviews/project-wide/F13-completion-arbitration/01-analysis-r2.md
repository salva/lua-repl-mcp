# Three distinct execution/result boundaries

User code returning is not validated completion: conversion, transfer and worker
record validation can still fail. A complete valid worker result received and
validated by the guardian before the hard deadline establishes deadline
eligibility, even when relay is delayed. Manager outcome application is a separate
logical recording point; public response commitment is the single-consumption
point. These must be named distinctly. Kill/cancellation can linearize at manager
acceptance before buffered results are logically recorded. Prior tests are not
authority; clarify ambiguous preservation wording consistently and preserve the
demonstrated delayed-relay deadline repair without inventing extra public IDs.
