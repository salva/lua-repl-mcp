# One explicit internal-to-public failure mapping

Focused option: map each private failure at manager output and correct startup
labels/allowed private records. One-level-up option: minimal typed internal
failure data carrying category, stage, observed exit and bounded message through
worker/guardian, translated once at the public boundary. Prefer the small shared
record if it eliminates repeated lossy translation; avoid a new generic error
framework. F05 owns the outer public result shape.
